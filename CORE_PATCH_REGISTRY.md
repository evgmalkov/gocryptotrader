# Core Patch Registry

> Реестр изменений ветки `scibot` **вне** каталога `exchanges/mexc/*` — то есть правок кода,
> общего для всех площадок (`ADR-218` `GCTU-14`/`GCTU-19`/`GCTU-26`).
>
> **Анонимных правок upstream не существует.** Каждая правка вне своего каталога несёт запись:
> ID · файл · причина · владелец · **измеримое условие удаления** · применение · судьба ·
> происхождение. Отсутствие записи = дефект, а не мелочь.

Создан пустым **до** анализа необходимости патчей: вывод «патч нужен» не должен существовать
отдельно от своей записи.
